# architecture-pro-insuretech
Учебный репозиторий по курсу "Архитектура ПО Pro", 8 спринт

## Оглавление задач

### [1. Проектирование технологической архитектуры](task_1_architecture_planning/README.md)
Анализ текущих проблем производительности системы и проектирование целевой архитектуры для повышения производительности и масштабируемости.

### [2. Динамическое масштабирование контейнеров](task_2_pod_autoscaling/README.md)
Реализация горизонтального автомасштабирования (HPA) на основе метрик памяти и RPS с использованием Kubernetes, Istio и Prometheus.

### [3. Переход на Event-Driven-архитектуру](task_3_eda/README.md)
Проектирование асинхронного взаимодействия между сервисами через события для снижения связанности и повышения отказоустойчивости.

### [4. Проектирование продажи ОСАГО](task_4_osago/README.md)
Разработка системы управления исходящим RPS к API партнёров с учётом SLA и ограничений по нагрузке.

### [5. Проектирование GraphQL API](task_5_graphql/README.md)
Проектирование GraphQL API для замены существующего REST API с оптимизацией запросов и гибкостью выборки данных.

### [6. Rate Limiting с Nginx](task_6_rate_limiting/README.md)
Реализация глобального rate limiting на уровне Nginx с использованием алгоритма leaky bucket для защиты от перегрузок.
